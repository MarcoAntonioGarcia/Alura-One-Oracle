## 🇬🇧 English

### 📖 Overview
This repository contains the applications, challenges, and exercises developed during the **ONE (Oracle Next Education)** program in collaboration with **Alura Latam**. The curriculum offers intensive training in software development and data analysis, blending theoretical concepts with hands-on engineering practices to build modern, scalable software solutions.

### 🏗️ Architecture & Structure
This repository functions as a monorepo housing several standalone projects, each representing a distinct challenge within the curriculum:

- **[`challenge-amigo-secreto`](./challenge-amigo-secreto)**: A web-based application to manage and draw names for a secret santa event.
- **[`challenge-conversor-moneda`](./challenge-conversor-moneda)**: A Java-based currency converter console application consuming external exchange rate APIs.
- **[`challenge-foro-hub`](./challenge-foro-hub)**: A RESTful API for forum topic management built with Spring Boot, Spring Security, JWT authentication, and Flyway database migrations.
- **[`challenge-literalura`](./challenge-literalura)**: A Spring Boot console application interacting with the Gutendex API for literature data processing and PostgreSQL persistence.

### 💻 Tech Stack
The projects across this repository showcase proficiency in a diverse set of technologies:
- **Backend Architecture**: Java 17+, Spring Boot 3+, Spring Data JPA, Spring Security
- **Data & Scripting**: Python, Pandas, NumPy, Matplotlib
- **Database Management**: PostgreSQL, MySQL, Flyway
- **Frontend / Client**: HTML, CSS, JavaScript
- **Infrastructure & Tools**: Docker, Git, GitHub

## 🇪🇸 Español

### 📖 Descripción General
Este repositorio contiene las aplicaciones, desafíos y ejercicios desarrollados durante el programa **ONE (Oracle Next Education)** en colaboración con **Alura Latam**. El plan de estudios ofrece una formación intensiva en desarrollo de software y análisis de datos, combinando conceptos teóricos con prácticas de ingeniería aplicadas para construir soluciones de software modernas y escalables.

### 🏗️ Arquitectura y Estructura
Este repositorio funciona como un *monorepo* que aloja varios proyectos independientes, cada uno representando un desafío distinto dentro del plan de estudios:

- **[`challenge-amigo-secreto`](./challenge-amigo-secreto)**: Aplicación web para gestionar y sortear nombres en eventos de "amigo secreto".
- **[`challenge-conversor-moneda`](./challenge-conversor-moneda)**: Aplicación de consola en Java para conversión de divisas, consumiendo APIs externas de tipos de cambio.
- **[`challenge-foro-hub`](./challenge-foro-hub)**: API RESTful para la gestión de temas de un foro construida con Spring Boot, Spring Security, JWT y migraciones Flyway.
- **[`challenge-literalura`](./challenge-literalura)**: Aplicación de consola en Spring Boot que interactúa con la API Gutendex para procesamiento de datos literarios y persistencia en PostgreSQL.

### 💻 Tecnologías Utilizadas
Los proyectos destacan la competencia en un conjunto diverso de tecnologías:
- **Arquitectura Backend**: Java 17+, Spring Boot 3+, Spring Data JPA, Spring Security
- **Datos y Scripting**: Python, Pandas, NumPy, Matplotlib
- **Base de Datos**: PostgreSQL, MySQL, Flyway
- **Frontend / Cliente**: HTML, CSS, JavaScript
- **Infraestructura y Herramientas**: Docker, Git, GitHub
